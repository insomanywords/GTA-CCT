Glitches & Guides

1. Matte + Pearl Glitch ▼
Effect: Apply Pearlescent over Matte paint.

1. Go to LSC > Respray > Primary > Matte.
2. Buy any Matte color.
3. Go to Metallic, scroll through list for 3-5 seconds (don't buy).
4. Back out, go to Plates (or Wheels), change something.
5. Go back to Respray > Primary > Pearlescent.
6. You can now select a pearl!
2. Patriot Tire Smoke / True Black ▼
Effect: Unlocks rare Patriot Smoke & "Super Black" paint.

1. Use this tool's "Tools" tab > "Copy #000000AA".
2. Go to Social Club Edit Crew page.
3. Use the Injector script from the Tools tab.
4. Save Crew & Restart Game.
5. In LSC, set Crew Color (Paint) & Crew Smoke (Tires).
3. Colored Chrome / "4D" Paint ▼
Effect: Shiny Chrome with a color tint.

1. Go to LSC > Respray > Primary > Chrome.
2. Apply Chrome.
3. Apply Crew Color immediately after.
Note: This preserves the chrome reflection under the color.
4. Secret Gold Paint ▼
Method 1 (Pure):
Metals > Pure Gold > Apply Crew Color (Yellow/Orange tint).

Method 2 (LSC):
Metallic > Bronze > Pearlescent > Race Yellow.
5. Chameleon + Pearl (Next Gen) ▼
Effect: 3-tone paint job.

1. Apply any Chameleon paint.
2. Do the "Matte/Metallic Scroll" glitch (Step 3 in Guide #1).
3. Change Plate.
4. Go to Pearlescent and apply any pearl over the Chameleon.

About

The ultimate utility for customizing vehicle colors in GTA Online. Created by ArtfulTwo79049.

OEM Library Credit: Special thanks to DCA (Digital Car Addicts) for curating the massive database of real-world replica colors.
View Source Spreadsheet 🔗

Features

  • 3D Visualizer: High-fidelity 3D preview featuring the Annis Elegy RH8 with real-time material simulation (Gloss, Matte, Metal, Chrome).
  • Advanced Mixer: Fine-tune RGB, HSL, and Alpha (Transparency) values.
  • Lighting Scenarios: Toggle between Daylight, Nighttime, and Streetlight to see how colors react to different environments.
  • Engine Simulation: Preview how colors will actually look in-game by simulating the RAGE engine's washout and brightness shift.
  • Reverse Engine Correction: Use the "Magic Correct" tool to calculate the exact hex code needed to counteract in-game washout and get your "Dream Color" on the streets of Los Santos.
  • OEM Library: Searchable access to 1000+ real-world paint codes (Ferrari, Porsche, BMW, etc.).
  • Build Manager: Save your favorite colors with details like manufacturer, pearl, secondary, and wheel colors.
  • Tools: Includes a "Silent Injector" script for mobile users, Neon Generator, and True Black helper.
  • Full Screen Mode: Compare colors directly against your TV screen.
  • PWA: Installs as a native app on iOS and Android (offline capable).

How To Apply Colors

  1. Create or Select a color in this tool.
  2. Tap COPY HEX (e.g., #FF0000AA).
  3. Go to the Rockstar Social Club "Edit Crew" page.
  4. Desktop: Right-click the color box > "Inspect" > Paste hex into the value field.
  5. Mobile: Copy the "Injector Script" from the Tools tab, create a bookmark, and run it on the Social Club page.
  6. Click "Save Crew" on Social Club.
  7. Restart GTA Online (or swap characters) to refresh crew data.
  8. Go to Los Santos Customs > Respray > Crew Color.
