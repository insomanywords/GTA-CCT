# GTA Crew Color Tool 🏎️

The ultimate utility for customizing vehicle colors in GTA Online. This tool bridges the gap between the Rockstar Social Club and the in-game RAGE engine, allowing you to create, preview, and inject perfect "Modded" and "OEM" colors with 100% accuracy.

**Current Build:** v10.33

## 🚀 Key Features

### 1. High-Fidelity 3D Visualizer
*   **Separated Lobe Pearlescent:** High-fidelity material simulation that decouples pearlescent highlights from environment reflections.
*   **Dynamic Environments:** Toggle between Showroom, Daylight (High Noon), Night, and Streetlight modes.
*   **Engine Simulation:** Real-time application of the **Tjakal Algorithm (1.58 Power Law)** to show exactly how your color will look in Los Santos.

### 2. Advanced Color Mixer
*   **Precise Control:** RGB, HSL, and Alpha (Transparency) sliders.
*   **Alpha Chips:** Quickly apply common transparency presets (AA, 00, EE, etc.) for modded crew effects.
*   **Image Picker:** Extract colors directly from reference photos or screenshots with a built-in zoomable picker.

### 3. OEM & Community Library
*   **1000+ Paint Codes:** Access a massive database of real-world colors (Ferrari, Porsche, BMW, etc.) curated by **DCA (Digital Car Addicts)**.
*   **Search & Filter:** Find the perfect hex code by manufacturer or color name.

### 4. Build Manager
*   **Save Favorites:** Store your complete vehicle builds including primary, secondary, pearlescent, and wheel colors.
*   **Export/Import:** Backup your collection as a JSON file or share it with friends.

### 5. Utility Tools
*   **Social Club Injector:** A JavaScript bookmarklet to instantly bypass Social Club's hex restrictions.
*   **True Black Generator:** Optimized shortcuts for "#000000AA" and neon saturation boosts.

## 📱 PWA Support
This application is a **Progressive Web App (PWA)**. You can install it on your Android/iOS home screen or Desktop for a full-screen, standalone experience with offline capabilities.

## 🛠️ Technical Details
*   **3D Engine:** Three.js (v160)
*   **Post-Processing:** `postprocessing` library for high-grade Bloom, SSAO, and Vignette.
*   **Mathematics:** Tjakal 1.58 Gamma Correction for in-game parity.
